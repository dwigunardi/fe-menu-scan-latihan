# Dokumentasi Backend (Snapshot)

Folder ini adalah **salinan dokumentasi dari repo backend** (`be-menu-scan-latihan`), disimpan di sini sebagai referensi kontrak API saat mengembangkan frontend. Beberapa link di dalamnya masih menunjuk ke path repo asal.

- **Sumber kebenaran untuk endpoint yang dipakai frontend** adalah kode di `src/lib/api/` dan ringkasannya di [`docs/fe/integration/api-endpoints.md`](../fe/integration/api-endpoints.md).
- Perbedaan yang sudah diketahui antara dokumen di sini dan kode frontend (misalnya `PUT` vs `PATCH`, path presensi, endpoint tutup shift) dicatat di bagian **"Perbedaan yang diketahui dengan `docs/be/`"** pada dokumen tersebut.
- Jangan mengedit isi folder ini untuk "membetulkan" kontrak; sepakati perubahannya dengan tim backend, lalu perbarui dokumen di repo backend dan salin ulang ke sini.
